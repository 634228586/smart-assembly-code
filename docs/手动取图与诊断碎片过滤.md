# Block / Tray 手动取图与诊断碎片过滤

## 用途

“相机与视觉”页面提供两个独立按钮：

- `Block 拍照取图`：使用 `blocks` 相机采集参数软件触发一张新图。
- `Tray 拍照取图`：使用 `trays` 相机采集参数软件触发一张新图。

这两个入口只负责采集和保存原图，不执行六色识别，也不要求九点标定。它们是当前颜色调参的正式入口：先在真实拍照点采集现场样本，再离线分析 HSV、面积、轮廓、中心和角度，并直接更新`camera.json`。

## 使用流程

1. 单独启动真实 MVS 视觉服务。
2. 将机器人置于对应的 Block 或 Tray 拍照点，并确认现场安全和画面内容。
3. 打开“相机与视觉”页面，点击对应的拍照取图按钮。
4. 界面显示保存成功、完整文件路径和原图预览。
5. 保留原始 PNG，不覆盖、不压缩；把保存路径交给后续离线分析。

图片按时间戳会话保存：

```text
data/sessions/
└── manual-{scene}-{timestamp}/
    └── manual-captures/
        └── {scene}/
            └── {scene}-{timestamp}.png
```

其中 `{scene}` 为 `blocks` 或 `trays`。每次请求使用新的时间戳，服务使用排他创建模式，拒绝覆盖已有图片。

## REJECT 微小碎片处理

检测仍会保留所有候选数据，真实目标选择逻辑不变。诊断图绘制时，对面积小于当前场景最小有效面积 5% 的不合格候选不再绘制红框和 `REJECT` 标签：

```python
diagnostic_reject_area_floor = float(config["min_area_px"]) * 0.05

if (
    not candidate["accepted"]
    and float(candidate["area_px"]) < diagnostic_reject_area_floor
):
    continue
```

该规则用于去除已经正确识别的大方块边缘、侧面反光或表面纹理形成的微小同色连通域，避免红字重叠。较大的不合格候选仍会显示，因此面积、形状或置信度接近阈值的真实问题仍可诊断。

不要仅为隐藏这些碎片而继续扩大形态学开运算核，否则可能侵蚀有效方块轮廓并影响中心与角度精度。

## 全分辨率处理的新鲜度窗口

3072×2048 工作区拍照会在采集后保存原图、生成并保存标注图，再执行颜色检测。该处理通常超过 1 秒，因此正式配置使用 `fresh_frame_max_age_ms = 5000`，避免把本次请求刚拍摄的新帧误判为过期。

安全检查仍然要求 `captured_at` 不早于客户端本次拍照请求的开始时间。提高处理窗口只允许本次新帧完成 PNG 编码、保存和检测，不允许复用请求前的缓存旧帧。
