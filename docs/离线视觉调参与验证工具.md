# 离线视觉调参与验证工具

## 启动

双击工程根目录中的`启动离线视觉工具.cmd`。

工具只读取本地图片，不连接MVS、机械臂或IO。它与正式视觉服务共用同一套候选判定算法，但不会执行九点坐标换算或机械臂运动。

## 基本流程

1. 选择`方块 blocks`或`托盘 trays`。工具只读载入`config/real/camera.json`中对应场景的检测参数。
2. 点击“添加图片”选择多张图片，或点击“添加文件夹（递归）”载入整个采集会话。
3. 点击“使用当前参数批量分析”。
4. 在图片列表中选择图片，并切换查看“原始图片”“六色HSV掩膜”“检测标注结果”。
5. 查看右侧逐色面积、形状置信度、长宽比、矩形填充率和拒绝原因。
6. 查看底部整批表格；每张图片六色均成功时总体才显示通过。

建议优先导入原始`point-N.png`，避免把已有文字和标记当作图像内容。`*-annotated.png`也可以分析，但仅适合复查。

## 参数预览

下方参数区可以修改：

- ROI：`x1,y1,x2,y2`；
- 最小/最大轮廓面积；
- 最低形状置信度；

六色HSV不在主界面中展开为大段JSON，避免占用图片区域。它来自当前正式`camera.json`或通过“加载候选JSON”读入的候选文件。点击“编辑六色HSV范围”会打开独立表格，每行填写一种颜色的H/S/V上下限；同一种颜色可以添加多个区间。确认后新范围只应用到内存，并自动重新分析当前已导入的全部图片。

修改ROI、面积或置信度时，旧分析缓存会立即作废；离开输入框或按回车后，工具自动校验新值并重新分析全部已导入图片。“应用参数到预览”按钮仍可用于主动确认。该操作只改变当前窗口内存，不写任何配置文件。图片会始终按照预览区域等比例缩放，完整显示整张原图、掩膜或标注图，不因原始分辨率产生滚动裁切。

## 候选文件

点击“保存候选JSON”会默认写入`data/offline_vision_candidates`。候选文件包含：

- 场景；
- 生成时间；
- 来源图片路径；
- 完整检测参数；
- `formal_camera_json_modified=false`标记。

候选文件不能被正式MVS服务直接当作活动配置使用。当前工具有意不提供“一键覆盖camera.json”，必须在整批真实图片验证和人工复核后另行更新正式配置。

## 结果含义

- `success`：存在可选择的有效候选；
- `not_found`：没有候选同时通过HSV、面积、形状和置信度限制；
- `ambiguous`：前两名有效候选的置信度差小于0.15；
- `REJECT`：候选存在，但至少一项面积、最小尺寸、长宽比或置信度不合格。

该工具当前用于手工调参和批量回测，尚未加入自动拟合HSV或YOLO训练功能。
