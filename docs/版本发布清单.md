# 版本发布清单

## 发布前

- [ ] `VERSION.json`版本、状态和日期正确。
- [ ] 包内 `.runtime`依赖检查通过。
- [ ] `requirements-lock.txt`与实际环境一致。
- [ ] MVS机器级前置依赖已记录。
- [ ] 正式代码、配置和标定生成 SHA-256清单。
- [ ] 所有关键赛前检查通过。
- [ ] 无硬件测试全部通过。
- [ ] 现场测试表全部填写并附证据。
- [ ] 正式目录中没有历史日志和旧 session。
- [ ] 在复制后的目录执行一次冷启动检查。

## 复制规则

完整复制“装配赛正式代码”目录，不单独复制入口脚本。复制后首先校验文件清单，再运行赛前检查。机器级 MVS驱动、网络、防火墙、VC++ Runtime、音频设备和 AI盒子不因复制目录自动完成配置。

校验命令：

```powershell
.\.runtime\Scripts\python.exe .\tools\verify_manifest.py
```

## 基线更新

真实配置或标定发生变化后，旧比赛授权立即失效。由操作者核验变更、运行测试并生成新基线；保留批准人、时间、旧哈希和新哈希。
