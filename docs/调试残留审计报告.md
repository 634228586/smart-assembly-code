# 调试残留审计报告

审计日期：2026-08-10。

## 结论

旧第31步不能直接转换为真机入口。其多层历史继承会把测试图像、测试标定、仿真授权、临时 IO和开发按钮带入可执行链路。本正式目录采用独立模块和 allowlist验证，不运行时导入任何历史数字步骤。

## 已隔离的风险类别

- 任务卡拍摄后改读预置图片；
- 工作区视觉绕过 MVS读取开发图片；
- 非真实数据来源被机器人端接受；
- 仿真标定或仿真点位进入运动；
- 临时颜色坐标用于计划生成；
- 临时 DO编号和有效电平进入真机；
- 仿真 IP、账号密码、TCP名称和速度成为默认值；
- 本地测试按钮生成可执行任务；
- 多个项目分别保存端口并连接到错误服务；
- 只检查端口连通、不核验服务身份；
- 历史绝对路径和旧 session结果被重新读取。

## 正式策略

- 运行代码只接受 `config/real`和 `calibration/real`。
- 真机值未知时使用 `UNSET`并禁用比赛。
- 图像必须属于当前 session且带同一请求号和新鲜时间戳。
- 工作区视觉只接受 `data_origin=camera_vision`。
- 端点使用角色化配置和身份握手。
- 正式运行模块执行 denylist扫描；测试样例与正式入口物理隔离。
- 历史日志、测试图、仿真标定和开发 sender不进入正式运行搜索路径。

## 当前未解决项

真实 AUBO身份、三套相机参数、两套颜色参数、活动 TCP、负载、四个关节点、两个红色抓放完整TCP（含各自接触Z）、真实 IO、两套九点标定、AI盒子端点和正式速度均尚未现场配置或验收。包内真实 MVS服务和厂商 Python wrapper已经实现并完成无硬件测试。
